# 団子屋 販売記録

高専祭の団子屋で使う、販売数と売上の記録アプリです。HTML 1ファイルだけで動きます。

- 商品ごとの「+」で1つ記録、「−」で直前の1件を取り消し
- 売上合計・販売数、「今日」と「全日合計」の切り替え
- 価格は「価格を変更」から変更（確認あり）。記録済みの売上は変わりません
- 「集計をコピー」で、集計・販売履歴・価格変更の記録を文章で取り出せます

## 注意

記録は、開いたブラウザの中（localStorage）に保存されます。端末どうしでは共有されません。
ブラウザの閲覧データを消すと記録も消えるので、閉店後に「集計をコピー」で控えを残してください。
iPhone と iPad など複数の端末で使う場合は、端末ごとの集計を合算してください。

## GitHub Pages で公開する

1. このフォルダを GitHub のリポジトリにプッシュする
2. リポジトリの Settings → Pages → Build and deployment で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける
